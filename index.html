PIXELFORGE STUDIO is a browser-based game creator for building playable games without installing a huge game engine. Build levels, add characters, enemies, collectibles and exits, then export your game.

A simple editor → a playable game → a shareable project.

Everything you need to start

PIXELFORGE is designed to make game creation easier while giving you real game systems to experiment with.

🎨 Build Levels

Add players, platforms, walls, enemies, coins, gems, keys and doors.

⚙️ Game Systems

Playtest with movement, jumping, collisions, health, score, collectibles and win/lose states.

📦 Export

Export a standalone HTML game that can be opened in a browser.
